### 02 · SQL Server MCP Server for AI Agents
**Read-only database integration · $19 USD**

A self-hosted Model Context Protocol (MCP) server that connects compatible AI agents to Microsoft SQL Server through controlled, read-only tools.

- Node.js and TypeScript
- Docker-based self-hosted deployment
- Read-only database tools
- Table-level permissions
- Admin panel and audit logs

Designed for developers and database teams who want AI agents to inspect permitted SQL Server data without granting unrestricted write access.

[**View product on Gumroad →**](https://fattandevops.gumroad.com/l/sql-server-mcp-server)

Product details: [products/sql-server-mcp-server.md](products/sql-server-mcp-server.md)
